# SmartClean Pro: marketplace B2B de aseo profesional

Prototipo de frontend para un **marketplace B2B de servicios de aseo profesional en Chile**: las empresas cotizan y contratan limpieza corporativa con factura electrónica, y los *partners* (personal de aseo verificado) gestionan sus trabajos.

## Vistas
| Ruta | Vista | Usuario |
|---|---|---|
| `/` | Landing page | Cliente |
| `/cotizar` | Cotizador de servicios | Cliente |
| `/dashboard` | Panel del cliente | Cliente |
| `/partner` | Trabajos disponibles y asignados | Partner |
| `/partner/perfil` | Perfil del partner | Partner |

## Ejecución local
```bash
npm install
npm run dev
```

**Stack:** React · TypeScript · Vite · Tailwind CSS · shadcn/ui · TanStack Query · React Router
